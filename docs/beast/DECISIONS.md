# MGR BEAST Decisions

Updated: 2026-09-30

1. **Truth beats demos.** Production-facing services cannot manufacture legal, financial, identity, provider, PII, or blockchain success.
2. **Provider-independent contracts.** Product workflows depend on MGR capability contracts; vendor adapters become live only after current-contract research + testing.
3. **Settlement is external truth.** Internal review/approval cannot create settled/refunded provider states.
4. **Founder superuser.** FOUNDER bypasses ordinary role gates; founder-only actions use dedicated guards.
5. **Legal authority remains deterministic/human-authorized.** Models/Jev advise or triage; they do not independently decide rights, eligibility, identity, notarization, payout, filing, or fund movement.
6. **Webhooks are hostile until authenticated.** Missing signature/shared-secret verification fails closed.
7. **No Git history rewrite without owner approval.**
8. **Batched CI.** Stack coherent repairs, then run one consolidated evidence pass.
9. **Old completion percentages are non-authoritative.** Current status comes from code + executed evidence.
