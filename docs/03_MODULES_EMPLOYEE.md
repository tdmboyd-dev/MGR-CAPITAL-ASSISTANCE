# Employee Module — MGR Capital Assistance

The Employee Module defines the entire employee experience, including tasks, ranks, payouts, training, and restrictions.

## 1. Employee Roles

### 1.1 Associate (Tier 1)
- Basic calling tasks.
- Script-driven.
- No team.
- Limited visibility.

### 1.2 Specialist (Tier 2)
- Handles more cases.
- Higher displayed commission.
- No team.

### 1.3 Senior Specialist (Tier 3)
- Mentors new employees.
- Higher displayed commission.

### 1.4 Team Leader (Tier 4)
- Manages a small team.
- Earns override commissions.
- Access to team performance dashboard.

### 1.5 Executive Partner (Tier 5)
- Highest displayed commission.
- Highest override.
- Can manage multiple teams.

## 2. Employee Tasks

Employees can:
- View assigned cases.
- Call clients.
- Send texts/emails.
- Upload signed documents.
- Update case notes.
- Complete training modules.
- Track their displayed earnings.

Employees cannot:
- See real surplus amounts.
- See backend filings.
- See county/state data.
- See true commission percentages.
- Export or print data.

## 3. Shadow Accounting

Displayed commission ≠ actual commission.

The system uses:
- Hidden base amounts.
- Hidden multipliers.
- Hidden overrides.

Employees see:
- “Commission: $X”
- “Rate: Y%”

Founder sees:
- True surplus.
- True fee.
- True payout.

## 4. Team Structure

Team Leaders and Executive Partners can:
- View their team.
- View team performance.
- Earn overrides.

They cannot:
- See real surplus amounts.
- See backend logic.
