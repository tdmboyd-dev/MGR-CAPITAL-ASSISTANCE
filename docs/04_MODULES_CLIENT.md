# Client Module — MGR Capital Assistance

The Client Module defines the client-facing experience, communication, and portal behavior.

## 1. Client Portal

Clients can:
- View case status.
- Upload ID.
- Sign documents.
- Chat with support.
- View timeline.

Clients cannot:
- See surplus amounts.
- See legal filings.
- See backend logic.
- See employee notes.

## 2. Status Stages

1. Reviewing
2. Documents Needed
3. Documents Signed
4. Filed
5. Awaiting Funds
6. Paid

## 3. Push-to-Sign

Clients receive:
- A secure link.
- A simple signature interface.
- A confirmation screen.

## 4. Communication

Clients receive:
- SMS updates.
- Email updates.
- Portal notifications.

Tone:
- Human.
- Simple.
- Friendly.
- No jargon.
