# Security & Protection Module — MGR Capital Assistance

## 1. Role-Based Access

Roles:
- Founder
- Admin
- Employee
- Client

## 2. Hidden Fields

Employees and clients never see:
- Surplus amounts.
- True commission percentages.
- Backend filings.
- County/state sources.
- Legal logic.

## 3. Case Shield

Prevents:
- Screenshots (where supported).
- Copy/paste.
- Printing.
- Exporting.
- Downloading.

## 4. Audit Logs

Tracks:
- Logins.
- Case views.
- Document uploads.
- Payout events.
- Admin overrides.

## 5. Data Encryption

- All sensitive fields encrypted at rest.
- All communication encrypted in transit.

## 6. Founder Mode

Only founder can:
- View real amounts.
- View backend logic.
- Modify AI behavior.
- Modify payout rules.
- Modify ingestion rules.
